Privacy Policy

This Privacy Policy outlines how data is handled on Aniket Kakad's personal developer portfolio (https://anik3t.vercel.app/).

1. Information Collection & Analytics

This website utilizes PostHog for usage analytics and session interaction monitoring. Collected telemetry includes:

  • Pageviews, section view milestones, and navigation link clicks.
  • Outbound link interactions (such as GitHub repositories and live project demos).
  • Scroll depth tracking milestones (25%, 50%, 75%, 90%).
  • Session replay recordings with automatic input masking and sensitive text masking enabled.
  • Unhandled JavaScript exception and rejection logs to ensure site stability.

2. Direct Communications

If you contact Aniket Kakad directly via email (aniketkakad8282@gmail.com) or phone (+91 92246 48203), any personal information provided (such as your name, email address, or message content) is used strictly to respond to your inquiry.

3. Advertising & Third-Party Data Sharing

This portfolio site does not display commercial advertisements, run ad-targeting pixels, or sell user interaction data to third parties.

4. External Links

This site contains links to third-party websites and platforms (such as GitHub, X / Twitter, and live project deployments). Clicking an external link directs you to that third party's platform, which operates under its own separate privacy policy.

5. Contact Information

For any questions concerning this website or its privacy practices, you can reach out via email at aniketkakad8282@gmail.com.
